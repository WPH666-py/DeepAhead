## 三、0–50 元窗口：每多花 1 元，性能提升多少（边际回报曲线）

把「用户从 DeepAhead 模式升级到原装模型」看作一次加价购买，取两端的成本与性能区间，得到每多花 1 元的回报：

| 升级动作 | 多付多少钱 | 性能增量 | **每多花 1 元 → 提升** |
|---|---|---|---|
| DSK → Kimi K3 | ¥10.3–11.2 | 0 ~ 8.5 分 | **0.00 ~ 0.83 分/元** |
| DSA → GPT-5.6 Sol | ¥14.1–15.0 | 0 ~ 13.2 分 | **0.00 ~ 0.94 分/元** |
| DSA → GPT-6 Astra | ¥37.3–38.2 | 0 ~ 14.7 分 | **0.00 ~ 0.39 分/元** |
| DSF → Opus 5 | ¥17.9–18.9 | 0 ~ 14.3 分 | **0.00 ~ 0.80 分/元** |
| DSF → Fable 5 | ¥37.2–38.2 | 0 ~ 14.6 分 | **0.00 ~ 0.39 分/元** |
| DSF → Fable 5.1 | ¥33.7–34.6 | 0 ~ 16.6 分 | **0.00 ~ 0.49 分/元** |

对照**纯模型加价链**（无 DeepAhead 参与，全部为实测分）：

| 升级动作 | 多付多少钱 | 性能增量 | 每多花 1 元 → 提升 |
|---|---|---|---|
| GPT-5.6 Luna → Terra | ¥7.45 | +5.9 分 | **0.79 分/元** |
| GPT-5.6 Terra → Sol | ¥7.19 | +8.2 分 | **1.14 分/元** |
| GPT-5.6 Sol → GPT-6 Astra | ¥23.19 | +1.5 分 | **0.07 分/元** |
| Opus 5 → Fable 5.1 | ¥15.76 | +2.3 分 | **0.15 分/元** |

**解读：** 在 0–50 元窗口里，最划算的「加价升级」其实是 Terra→Sol（1.14 分/元）与 Luna→Terra（0.79 分/元）；而旗舰级加价（Sol→Astra、Opus5→Fable5.1）回报已跌到 0.07–0.15 分/元。DeepAhead 模式那一侧，DSK/DSA/DSF 的「花小钱办大事」体现在起点极低、且每元回报上限（0.39–0.94 分/元）与中端加价链同量级——但**下界为 0**：一旦模式性能达到原装引擎上限（未测），加价买原装模型的回报就是 0。

## 五、方法、假设与限制（重要）

1. **性能分 = BenchLM 综合指数（0–100，2026-09-04 快照）**，同一套方法论覆盖全部 9 个有公开排名的模型；它混合多模态/知识/推理等维度，与「智能体编码」视角互补（图 4 用 DeepSWE v1.1 单一基准交叉验证）。
2. **DeepSeek V4 Flash 无公开综合排名**（40 行已发布、未达排名门槛），因此主图只标其价格点；已发布实测行（DeepSWE 54.4%、SWE-bench Vals 88.8%、LiveCodeBench Vals 87.3%、Terminal-Bench 2.1 Vals 67.0%）供参考。
3. **单任务成本模型**：标准 Agent 负载 = 20 次调用 × 每次 50K 输入（70% 前缀缓存命中，按各家缓存价计费）+ 每次 2K 输出（与 Apidog「agentic coding loop」示例同形）。成本 = 输入×单价 + 缓存×单价 + 输出×单价，按 1 USD = 6.78 CNY（2026-09-08 外汇中间价 6.7804）。真实成本受上下文长度、缓存命中率、推理 effort（OpenAI reasoning 输出按输出价计费）与重试次数影响。
4. **DeepAhead 模式成本**：只烧 DeepSeek Token（`docs/WORKFLOW-ENGINES.md`），按「规划/委派/审查阶段增加 1–5 次模型调用」折算运算量：DSH +0%、DSK +15%、DSA +20%、DSF +25%；默认模型 `deepseek-chat`（→ V4 Flash），升级档 `deepseek-v4-pro`。
5. **DeepAhead 模式性能没有独立公开基准，这是本分析最大的限制。** 图表中的模式性能为区间外推：下界 = DeepSeek V4 Pro 可比较综合分 66.4（同厂同代中可公开比较者），上界 = 对应原装引擎的模型分数（DSK→74.9、DSA→81.1、DSF→83.0）。它表达的是「引擎上限」，不是实测。若自行跑统一基准（建议 Terminal-Bench 4.0 / DeepSWE v1.1），可直接替换 `build.py` 中 `mode_scores` 与 `DEEPSWE` 的数值。
6. **价格时效**：GPT-5.6 Sol 促销价至 2026-11-21；OpenAI 7-30 曾对 Terra/Luna 降价；DeepSeek 已预告整体涨价但未公布替代价。所有价格均有公开来源，见第六节。
7. **公平性**：原装模型分数来自厂商自报与第三方混排（BenchLM 标记 verification），Fable 5 / Opus 5 / Astra 的「最佳 effort」数据与其现实使用形态（如 effort 档位、部署方式、订阅 vs API）可能不同；DeepAhead 模式对比的是**API 等价**成本。
