## DeepAhead v0.3.0

本次版本围绕「可观测性 / 视觉引擎 / 上下文管理 / 输入体验」做了六项改动。

### 📋 工具 → 日志

顶栏原来的「🛠 工具」改为「📋 日志」，统一汇总：

- **模式切换**（DSH / DSK / DSA / DSF，含引擎与机制）
- **每轮提出的问题**（含带入的上下文文件）
- **AI 的回复**
- **全部工具调用结果**（参数、成功/失败、输出）
- **操作过程**（审批放行/拒绝、Agent Loop 完成摘要、文件变更）
- **上下文压缩**（压缩前后 Token）

每条日志可按类型筛选色标、逐条展开详情，也可一键「清空日志」。日志独立于对话，**清空会话后日志依然保留**。

### 🤖 勾选「工具」即默认 Agent 模式

AI 配置中勾选「工具」即默认走 9 工具 Agent Loop（自主调用工具直到得出结论），输入区同步显示「Agent 模式 / 对话模式」徽章；取消勾选才退回单轮对话。

### 🖼「多模态」→「视觉引擎」

- 开关与配置项统一改名为「视觉引擎」。
- **若当前连接的模型本身不具备多模态（识图）能力，界面会明确提示需要搭配视觉引擎使用。**
- 纯文本模型且未配置视觉引擎时，粘贴图片会被拦截并给出配置指引（勾选视觉引擎 → 填 Vision API Key / Base URL / Model）。

### ⌨️ 本地终端不再弹 CMD

「本地终端」只打开应用内置 Terminal 面板，**不再拉起系统 CMD / Windows Terminal 黑框**。命令结果直接留在面板内，支持导出、复制、清空。

### 📝 输入区增强

- 输入区整体加高（文本框更高、内边距更宽松）。
- 支持**直接复制粘贴图片**，最多 **6 张 / 次**，缩略图缩小展示。
- 输入区**随图片数量增多而向上增高**。
- 「+ 添加文件」右侧新增「🗑 **清空会话**」：清空右侧 AI 对话内容与上下文占用统计，**日志内容保留**。

### 📊 上下文占用比例与压缩

新增实时上下文占用显示（Tokens / 窗口大小 / 百分比），并支持两种压缩模式：

- **手动压缩**：占用超过 **85%** 时提示「建议压缩上下文或清空当前对话」，由你决定何时压缩（面板内可随时点「立即压缩上下文」）。
- **自动压缩**：占用超过 **85%** 时**自动压缩用户上下文**（保留最近轮次），**不清空对话**。

后端 `ContextCompressor` 改为按比例阈值（默认 0.85）触发，并支持调用方传入上下文窗口；Agent 循环每轮推送实时占用事件。

---

### 技术改动

| 层 | 改动 |
| --- | --- |
| 后端事件 | `AgentEventKind` 新增 `ContextUsage { tokens }`（每轮推送实时占用） |
| 后端命令 | 新增 `estimate_context_usage` / `compress_context` / `get_context_config` |
| 后端参数 | `send_ai_message_with_tools` 新增 `context_limit` 与 `auto_compress` |
| 上下文 | `CompressorConfig` 阈值改比例制（`warn_ratio`，默认 0.85），新增 `usage_ratio` 与单元测试 |
| 前端 | `stores/app.ts` 新增 `sessionLogs` / 上下文占用与压缩 / 多图附件；`EditorPage.vue` 日志面板与输入区重构 |

### 安装

下载 `DeepAhead_0.3.0_x64-setup.exe` 安装即可（Windows x64，NSIS 当前用户安装）。
