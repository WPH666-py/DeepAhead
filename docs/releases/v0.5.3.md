## DeepAhead v0.5.3

**「开始」菜单新增「🔄 更新 DeepAhead」——点一下就自动卸载旧版并装新版。**

---

## 🔄 开始菜单新增更新入口

```
开始 ▾
  新建项目 / 打开项目
  ─────────────
  保存 / 另存为
  ─────────────
  软件和插件市场
  ─────────────
  关闭项目
  ─────────────
  🔄 更新 DeepAhead（当前 0.5.3）      ← 新增
  ─────────────
  卸载 DeepAhead / 退出
```

点击后**直接走完整更新流程**，不再二次确认（用户已经明确点了「更新」）：

1. 检查 Gitee 上的最新发布
2. 发现新版本 → 显示进度框并**立即开始下载**（约 96 MiB，带进度条）
3. 下载完成后**自动退出应用**
4. 游离脚本接手：**静默卸载旧版 → 静默安装新版 → 自动重新启动**

菜单项会显示**当前版本号**，便于确认自己装的是哪个版本。

### 三种"不更新"的情况都会明确告知，不会静默

| 情况 | 行为 |
|---|---|
| 已是最新 | 弹提示：当前版本 + Gitee 最新发布 |
| 无法访问 Gitee | 弹提示：检查网络后重试 |
| 有新版本但该发布没有安装包附件 | 弹提示并说明需手动下载 |

### 更新进行中不允许"推迟"

如果更新已经在下载/安装中，点「暂不更新」或关闭弹框会被拒绝并提示原因——
否则会出现"界面显示已推迟、后台却把应用重启了"的错愕行为。

## 与既有入口的关系

现在共有三个更新入口，行为各有侧重：

| 入口 | 行为 |
|---|---|
| **开始 → 🔄 更新 DeepAhead** | 点击即直接下载安装（本版新增） |
| **AI 驾驶舱 → 🔄 检查更新** | 只检查并报告结果，不自动安装（排查用） |
| **启动时自动提示** | 发现新版本即弹框，由用户选「暂不更新 / 立即更新」 |

## 验证

- `cargo test --lib -- --ignored live_gitee` → **2 passed**（真实 Gitee 网络：检测到最新发布 + 安装包可下载、MZ 头校验通过）
- `vue-tsc --noEmit` → 0 错误
- `cargo check` → 0 错误

## 安装

下载 `DeepAhead_0.5.3_x64-setup.exe` 安装（Windows x64，NSIS 当前用户安装）。

> 如果你现在装的是 **0.4.x**，请手动安装一次本版——0.4.x 没有自动更新功能。
