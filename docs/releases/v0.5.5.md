## DeepAhead v0.5.5

**执行许可改成三档，档位接管规则引擎的全部开关；裁决卡片只剩一个问题：放行，还是拦截。**

---

## 🔐 执行许可三档（取代原来的两档）

| 档位 | 规则引擎 | 逐调用确认 | 裁决卡片 |
| --- | --- | --- | --- |
| **需逐步确认** | 全开 | 每一个工具调用都查给你看 | 有 |
| **仅确认风险操作** | 全开 | 只有风险操作（写盘 / 命令 / 删除 / 推送）才查 | 有 |
| **全流程开放** | **全关（所有操作永久放行）** | 无 | 无 |

在「AI 配置 → 执行许可」里以卡片式选择器切换，每张卡片直接写明该档位下规则引擎的状态。

## ⚖️ 规则引擎的开关不再交给用户自选

「集成能力 → 规则引擎」里的三个开关（引擎 / 裁决卡片 / 任务契约）改成**只读状态**：它们由执行许可档位唯一决定。

- 选「全流程开放」→ 规则引擎**所有开关全关**，所有操作**永久放行**（不产生硬门、不产生裁决卡片）；
- 选「需逐步确认」或「仅确认风险操作」→ 规则引擎**所有开关全开**。

以前那种"开关拨了没反应 / 拨成互相矛盾的组合"从此不可能再出现。

## ❌ 放行 = 自动「继续」，✅ 拦截 = 换方案

裁决卡片上的两个按钮语义重写，只有一个问题：**放行，还是拦截？**

- **❌ 放行**：后端登记一条**一次性放行**（工具名 + 操作类型 + 路径三维匹配），被拦的调用重试时直接通过硬门；
  若这一轮循环已经结束，前端**自动回复「继续」**再跑一轮，并告诉模型"就是刚才那个调用，立刻重试"。
- **✅ 拦截**：拦下该操作，模型换方案或先向你确认。

审批卡片（需逐步确认 / 仅确认风险操作档位）用同一套语义色：❌ 红 = 放行并自动继续，✅ 绿 = 拦截。

## 🖼 DeepSeek 原生多模态（V4-exp 起）

文案与判定全部纠正：**DeepSeek 自 V4-exp 起原生支持多模态（识图）**，`deepseek-flash` / `deepseek-chat` / `deepseek-reasoner` 等型号可直接粘贴图片识别。

- 「AI 配置」弹窗标题改为 **Deepseek-API 运行时**；
- 模型提示词补上 `deepseek-flash`；
- 视觉引擎（DeepSeek-OCR / ModLens）重新定位为**可选增强**：截图、扫描件、公式、复杂表格更稳，但**不再是识图的前提**；
- 只有历史纯文本型号（`deepseek-coder` 老版本等）才会提示需要视觉引擎中转。

## 💾 日志实时落盘到安装目录

日志面板里的每一条记录（模式切换、每轮提问与回复、全部工具调用、操作过程、规则裁决）现在都**实时写入磁盘**：

```
%LOCALAPPDATA%\DeepAhead\logs\deepahead-YYYY-MM-DD.log
```

- 面板头部显示完整落盘路径，并提供「📂 日志目录」按钮直接打开；
- 后端 Agent 循环的规则决策、审批应答、待决裁决、续跑注入也写进同一份文件，时间线自然对齐；
- 单文件 8MB 轮转（保留一份 `.log.1` 历史），写盘失败静默降级，绝不拖垮主流程。

## 🎨 界面审美刷新

- AI 配置弹窗：更宽的呼吸感、层次标题、卡片式档位选择器；
- 集成能力面板：规则引擎开关改为带状态圆点的只读列表，档位徽标一目了然；
- 日志面板：落盘路径条 + 目录入口按钮；
- 裁决卡片 / 审批卡片：统一的语义色、圆角与阴影层次。

- 自动更新照旧：启动后若检测到 Gitee 上有更新，会提示下载并静默重装。
