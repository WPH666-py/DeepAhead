## DeepAhead v0.4.0

本版把五个 DSH 生态插件的核心能力**内置**进 DeepAhead，并新增记忆协议与主模型约束。

---

### 🌳 Git 提交 → 「Git 面板」

- 顶栏「Git提交」改为 **🔀 Git 面板**（下拉菜单）。
- 下拉含两项：**⬆ Git 提交**（原推送面板，重命名为「提交并推送」）与 **🌳 历史提交记录**。
- **历史提交记录**集成 `dsh-git-graph` 的功能：
  - **算法逐行移植** `computeLanes`（单遍贪心"待定泳道"）：分支头**追加到最右**、`later` 父集合过滤、合并汇入的显式 `gap`、首父继承泳道、只裁尾部空位。
  - 数据源与上游一致：`git log --branches --tags --remotes --topo-order --parents`，`%x00` 字段分隔 + `%x1e` 记录分隔，`%at` epoch 秒（不在 Rust 侧格式化，避免二次解析失真），**多取一条**判断 `hasMore`。
  - 字形渲染 `●` 提交 / `◆` 合并 / `│` 贯穿 / 空格；引用徽标（当前分支高亮）；相对时间；**加载更多**（初始 200，每次 +100）。
  - 额外增补：点击提交展开该提交的改动详情（文件列表 + diff）。

### 🧩 「集成能力」面板（新增）

顶栏新增 **🧩 集成能力**，五个页签：

#### 📊 费用统计（集成 `dsh-cost-meter`）
- DeepSeek 价目表（USD / CNY 双表），含 **off-peak / peak / legacyBase** 三档与调价边界。
- 单次调用成本公式对齐上游：每 1,000,000 token、**`cacheWrite` 回退到 `cacheHit`（不是 cacheMiss）**、账本内**永不取整**。
- 峰谷判定：UTC `01:00–04:00` / `06:00–10:00` 为高峰，**周末全天低谷**。
- 账本按本地日键聚合，天 / 会话 / 按供应商-模型桶同时记 **`cost` 与 `apiCost` 双轨**；预算比例、缓存命中率、按模型排行。
- **未知第三方模型保持 unpriced（不计价），绝不当作 0**；账本原子写（临时文件 + rename）。
- 支持币种切换、清空历史。

#### 🗜 上下文压缩（压缩引擎替换为 `billion-context`）
- 采用其 kernel 的核心主张：**摘要由模型自己写**，引擎只负责引用分配、nudge 判定、成对完整性替换。
- 移植要点：
  - **CJK 感知 token 估算**（CJK ≈ 1 token/字，其余 ≈ 4 字符/token），替换原先的 `chars/2.5`。
  - **引用 `mNNNNN` 永不重发**（游标 = 已用最高序号 + 1，向上找空位；剪枝后重新钉住高水位）。
  - 阈值逐项对齐代码：**OVER-LIMIT 75% / EMERGENCY 95% / 首次质量水位 45%**，增长步长**恒定 50000**（不随窗口缩放）、增长门槛 **22500**、T1/T2 目标 50000/75000、最小可压范围 **5000 字符**、摘要 50–20000 字符、保留最近 5 条 / 5000 token。
  - **成对完整性**：工具调用↔结果、推理↔回复边界扩张到不动点（DeepSeek thinking 模式要求 reasoning 回传，拆对会 400）。
  - **空操作硬报错**（完全覆盖且无新消息时不"假装成功"，防活锁）。
  - **压缩成功后重置 nudge 基线**（否则会形成提示反馈环）。
  - 剪枝时**无条件钉住首条用户消息**；剥离孤儿（结果无调用 / 调用无结果）。
  - 无损内容存储支持 `decompress` 取回。
- 面板显示引擎全部阈值，便于核对。

#### 🧠 长期记忆（集成 `dsh-memory-protocol`）
- 忠实移植其**协议语义**：轮首自动 `weave`（检索并把结果注入上下文）、轮末自动归档本轮内容、**每轮重置**的门。
- 保真要点：记忆工具**自身永远放行**（否则死锁）；**"成功但为空"同样满足门，"失败"不满足**；截断上限 **查询 2000 / 注入 8000 / 归档 4000 字符**；**失败开放**（后端不可用时放行并提示，而不是把应用锁死）。
- 无 MCP / 无 Python 的最小可用实现：每用户固定路径 JSONL + **BM25 + 字符二元组**检索（对应上游 `embedder.mode=fallback`）+ 近因加权。
- 工具：`memory_weave` / `memory_ingest` / `memory_search` / `memory_status` 已注册进工具表，模型可主动调用。
- 面板可开关五项配置、查看最近记忆、一键清空。

#### 🛡 规则引擎（集成 `dsh-rule-engine`）
- 解析 `$DSH_HOME/AGENTS.md` 的**格式契约**：章节 / `### [规则 N] 标题` / **free-zone 跳过** / `执行等级` / 四要素（触发·检查·动作·豁免）。
- 等级 → 动作（`A`拒绝 / `B`纠正 / `C`询问 / `D`自证 / `M`元规则），置信度派生（等级∧触发∧检查∧(动作∨含D) → high）；**低置信规则永不硬拦**。
- 工具分类表（analysis / artifact / mutating / unknown + 前缀规则），**`write`/`edit` 属 mutating**（走完整严格链）。
- 只读命令判定：引用感知分段（`2>&1` 的 `|` 不当分隔符）+ 别名归一 + **每段都必须只读**，未知段即非只读。
- **已在 Agent 循环的工具执行前接入硬门**：旁路窗口 → 自保护（`AGENTS.md` 等保护文件需 unlock）→ 内联命令禁令（`node -e` / `-c`）→ 重试熔断（第 3 次相同失败调用）→ **意图直判**（本轮无执行子句则拒绝变更类工具）→ 授权范围匹配（类型 + 路径前缀边界）。
- 拒绝信封与上游同形：`[guardian:ruleN] 理由（规则 N｜误判可打标：/guard label ERR-XXXXXX incorrect）`；审计账本 JSONL + 2MB 轮转保留 400 行。
- 面板显示规则清单、置信分布与最近审计。

#### 🔍 插件体检（集成 `dsh-plugin-vet`）
- 移植其**评分模型**：权重 critical 45 / high 20 / medium 8 / info 0，置信系数 certain 1.0 / likely 0.8 / heuristic 0.5，`staticScore = clamp(round(100 − Σ(权重×系数)), 0, 100)`。
- **判决只由非 heuristic 发现决定** —— 这是原插件的信任边界，已刻意保留。
- 规则：R1 构造链逃逸 / R2 动态执行 / R3 process 高危成员 / R4 原型污染 / R6 混淆（须与动态执行同现）/ R7 硬编码密钥（占位符排除）/ R9 死循环与超大分配 / R11 敏感路径删除写入 / R12 bundle 契约（含 patch 文件存在性与入口）/ R13 外传端点（守卫上下文降噪）/ R14 非 JS 脚本下载执行 / R16 幽灵与僵尸依赖 / R17 `!!js` 配置注入（危险动词 × 外传/凭证双组合升级为 high）/ R20 子进程参数下载执行（**要求 child_process 绑定**）。
- **能力清单（N1）**：网络主机 / 敏感路径 / 子进程 / 依赖 / `hasNetwork` / `hasExec`。
- 评分卡**两段式**：静态块（判决 + 静态分 + 分项构成 + 发现 + 能力清单）与人工审计健康档案**刻意不合并成一个数字**。

### ⚙️ 主模型只支持 DeepSeek

AI 配置的 Model 改为**下拉选择**（`deepseek-chat` / `deepseek-reasoner` / `deepseek-coder` / `deepseek-vl`）或自定义，但保存时**校验必须为 DeepSeek 模型**（允许代理前缀写法如 `deepseek-ai/DeepSeek-V4`）；历史配置里的非 DeepSeek 模型在启动时自动回退为默认值。

### 诚实说明（做了哪些保真取舍）

- **billion-context**：移植的是可移植内核（引用/分级/阈值/成对完整性/剪枝/内容存储）。原插件的 HTTP 代理层、CCR 落盘导出、图像压缩、语义检索（上游自身也未实现）未移植。`compress` 工具已注册，模型可按 nudge 提示分批折叠。
- **dsh-plugin-vet**：原插件的 **R1–R5 建立在 TypeScript 编译器 AST 上**（作用域/遮蔽/常量折叠/别名追踪）。本实现用正则 + 启发式，因此这些规则标记为 `heuristic`/`likely` 且**永不单独把判决推到 critical**；R8/R10/R15/R18/R19 与 OSV 漏洞库查询未实现。
- **dsh-rule-engine**：移植机制层与硬门。LLM 意图兜底、文本注入纠正通道、任务契约、turn card 与远程服务面板未移植（原插件的浏览器 UI 在其独立包 `dsh-rule-engine-client` 中，不在该仓库内）。
- **dsh-cost-meter**：移植纯计算层（价目表/公式/峰谷/账本/预算/格式化）。官方价格页抓取、供应商余额、编码套餐额度、外部用量快照未移植；计量由 Agent 循环直接记账（不依赖 DSH 的 `llm/stream` 水龙头）。
- **dsh-memory-protocol**：原插件的记录 schema / 排序 / 保留策略在**未读取的 Python `memory-skill` 服务**里，本项目按其"MCP 不可用时的 BM25 降级路径"实现。
