## DeepAhead v0.4.1

本版补齐 `dsh-rule-engine-client`，并把规则引擎从"能拦"推进到"**可裁决、可学习、可调**"。

---

### ⚖️ 回合末裁决卡片（集成 `dsh-rule-engine-client` v0.1.0）

按上游 client bundle 的**契约**逐项实现，而非自行发挥：

- **挂载位置**：助手消息下方（对应上游 `conversation.chat.assistant-actions` 槽位，order 20，与官方 feedback 共存）。
- **卡片内容**：用户原文、被拦工具与参数摘要（≤80 字符）、命中规则编号、拦截原因。
- **两个按钮**：**✅ 拦对了 / ❌ 拦错了** —— 点选即登记判例。
- **判例一次性锁定**：选定后按钮消失并显示「✓ 已判：拦对了」/「✗ 已判：拦错了」，不能在卡片上改判。改判走 `/guard label <ERR-码> <correct|incorrect>`（命令行是有明确意图的操作，保留为改判通道）——这是上游刻意的设计，因为 ❌ 会影响后续行为。
- **同一回合多次被拦 → 一张卡片内逐条分组**：每条独立展开、**独立 ✅/❌**（不共用一对按钮）、独立一次性锁定，标题显示进度 `已判 2/3（✅1, ❌1）`。
- **❌ 登记命令指纹 → 同类命令下次直接放行**（7 天 TTL），与 `/guard label ... incorrect` 同一链路；可用 `/guard label clear <指纹>` 撤销。
- **危险命令永不产生指纹**（`rm -rf` / `Remove-Item -Recurse` / `git reset --hard` / `git push --force` / `curl | sh` 等）——因此**不可能被"学习放行"**。这是安全性质，有专门测试守着。
- **指纹归一化**：数字 → `<n>`、绝对路径 → `<path>`，所以 `git add D:/proj/a.txt` 与 `git add D:/proj/b.txt` 同指纹（同类命令），而危险形状直接返回 None。
- **落盘** `$DSH_HOME/rule-engine-turn-cards.json`，上限 **200** 张（超出裁最老的）；判例落 `$DSH_HOME/rule-engine-labels.json`。
- **默认关闭**（对齐上游"面向大众默认关"），由设置页开关控制；关闭时不产生卡片、不落盘。

### 🛡 `/guard` 命令行（面板内）

「集成能力 → 规则引擎」页签新增命令行，已实现 14 个子命令：

```
status / rules / active / log [N] / cards [N] / labels
unlock [N] / bypass [N] / lock / revoke / reload
label <ERR-码|指纹> <correct|incorrect> / label clear <指纹>
freedom
```

- `unlock` / `bypass` 窗口会**写回全局配置**，下一次 Agent 运行即刻生效（不再需要重启）。
- `revoke` 清空全部授权与指纹放行。
- `freedom` 输出**诚实清单**：已实现的机制 vs 未实现的能力（见下）。

### 🎛 规则引擎开关即时生效

新增「回合末裁决卡片」与「任务契约」开关（同组，默认关），写入后端全局配置，**即时影响 agent loop 的硬门与卡片生成**；选择结果本地持久化并在启动时回填。

### 🔧 改进（一并修复）

- **测试不再污染真实用户状态**：此前测试会写入真实 `~/.dsh/rule-engine-labels.json`。现在存储路径可通过 `DEEPAHEAD_RULE_ENGINE_DIR` 覆盖，标签相关测试全部改用独立临时目录。
- **指纹路径归一化修复**：原先只识别 `:\`，在命令被小写化后 Windows 盘符路径（`d:/...`）逃逸归一化，导致同类命令指纹不同。已补 `:/`。
- **`/guard` 空命令**：无子命令时返回用法而不是静默走 status。

### 仍未实现的诚实清单

规则引擎的以下能力**未移植**（`/guard freedom` 也会如实输出）：

- LLM 意图兜底（上游的「非对称救援」需要 LLM 路由）
- 文本注入纠正通道（助手文本审计：交付声明、时间证据、批评冻结等 20 项检测）
- 任务契约与反过度设计（modes / budgets / hash 策略）——仅保留开关位
- 质量账本、热词学习、技能授权实时对账
- `/guard` 的 `approve` / `mode` / `budget` / `contract` / `quality` 子命令

另外三项保真说明（与 v0.4.0 一致）：`dsh-plugin-vet` 的 R1–R5 因缺少 TS AST 而降级为启发式（**永不单独把判决推到 critical**）；`billion-context` 未移植 HTTP 代理层与 CCR 落盘；`dsh-cost-meter` 未移植官方价格页抓取与供应商余额。
